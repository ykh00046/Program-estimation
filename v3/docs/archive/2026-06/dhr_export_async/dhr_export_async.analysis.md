## 3. 핵심 위험 정밀 검사 — 워커 위젯 접근 잔존: **위반 0**

- A `_run_export_pipeline` 내부 식별자 전수 확인: 파라미터(스냅샷)·config·exporter만 —
  `worker_name`은 config 읽기 property(위젯 아님). 위젯 접근 0건.
- B `job()` 클로저 캡처 변수 전수 확인: 전부 비위젯 값(파싱 결과/스냅샷). 위젯 호출은 클로저 밖에서만.
- Plan 리스크 표 최상위 항목("파이프라인 내부 위젯 접근 잔존, 높음") 완전 해소.

## 4. 차이점 (모두 무해/개선)

- `_exporting_product` 필드 + 완료 로그 추가 (설계엔 `_exporting_lot`만 — 관측성 보강)
- closeEvent `if owner is not None` 이중 가드 (설계보다 견고)
- closeEvent 검증은 검수로 처리 (설계 §4가 허용한 선택지)
